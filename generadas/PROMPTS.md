# Los 7 prompts sketchnote — español, listos para pegar

Siguen `.claude/skills/video-visuals/SKILL.md`: apertura fija, 8–15 elementos etiquetados, contornos
de color fuerte con rellenos suaves a lápiz, cierre fijo con lista negativa, formato 16:9.

**Sin Levy.** Levy es la mascota de SaaS Factory; este material es de A2A Factory y va a un cliente.
Mezclar mascotas ensucia la marca.

**Comando** (una imagen, o `todas`):

```bash
python3 generadas/generar.py 1 01-portada
python3 generadas/generar.py todas
```

⚠️ **No uses el script del skill** (`.claude/skills/image-generation/scripts/generate-image.ts`):
está roto contra la API actual de OpenRouter por dos motivos, verificados el 2026-08-31 —
su modelo por omisión fue retirado (400 «not a valid model ID») y busca la imagen en
`message.content`, cuando hoy llega en `message.images[0].image_url.url`. Arreglarlo es un
cambio de repo con su propio PR; `generar.py` lo sortea sin tocar el árbol de trabajo.

**Acentos — resuelto en la imagen piloto (2026-08-31).** El modelo NO destroza los acentos: los
escribe bien cuando la etiqueta viene acentuada en el prompt, porque copia literalmente lo que va
entrecomillado. Por eso las cadenas de etiqueta llevan sus tildes y el respaldo de "vocabulario sin
acentos" quedó descartado; el español completo se mantiene.

**Lo que sí falló en la piloto y cuesta una regeneración:** pedir "cada elemento con su etiqueta"
sin dictar el texto. El modelo se inventa las palabras y además las escribe en inglés
("CARGO SHIP", "Delivery comingzo"). Regla: o se dicta la palabra exacta, o el elemento va sin
etiqueta — nunca se deja la decisión al modelo.

**Riesgo conocido:** `--aspect 16:9` no fuerza el lienzo; es una instrucción en lenguaje natural
dentro del prompt (`generate-image.ts:76`). El modelo puede ignorarla. Se verifica a ojo en cada
imagen y se regenera la que salga con otra proporción.
